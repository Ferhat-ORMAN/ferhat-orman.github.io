# Ferhat Orman kişisel sitesi

Saf HTML, CSS ve JavaScript ile yazılmış tek sayfalık CV sitesi. Derleme adımı ya da harici kütüphane yok.

## Dosyalar

| Dosya | İçerik |
|---|---|
| `index.html` | Sayfa içeriği |
| `style.css` | Tüm stiller |
| `fx.js` | Canvas efektleri: yıldız alanı, galaksi, isim parçacıkları, kayan yıldız, warp, imleç |
| `script.js` | FX düğmesi, tercih kaydı, kaydırınca açılma, menü geçişleri |
| `404.html` | GitHub Pages hata sayfası |
| `favicon.svg` | Sekme simgesi |
| `assets/Ferhat_Orman_CV.pdf` | İndirilebilir CV |

## Yerelde açma

`index.html` dosyasına çift tıklamak yeterli.

## Efektler

Üst menüdeki **FX** düğmesi efektleri açıp kapatır ve tercih tarayıcıda saklanır. İşletim sisteminde "hareketi azalt" ayarı açıksa site efektler kapalı başlar.

## Projeler bölümünü ekleme

`index.html` içinde "Projeler bölümü" yorumunun arasındaki bloğu açın, örnek kartı her proje için çoğaltın ve menüdeki `Projeler` satırının yorumunu kaldırın. Kartlar mevcut `card` stilini kullandığı için CSS değişikliği gerekmez.

## Yayınlama

Depo adı `ferhat-orman.github.io` olmalı. Settings → Pages → Source: "Deploy from a branch", Branch: `main`, klasör `/ (root)`.

## Not

`assets/Ferhat_Orman_CV.pdf` telefon numarası ve fotoğraf içerir. Site yayında olduğu sürece herkes indirebilir.
